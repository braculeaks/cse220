--- Before starting the Quiz:
1. Make sure you do not have any mobile devices or other study materials with you.
2. Turn on the AutoSave option in VS Code. Otherwise, your file will not be saved.


During the quiz:
1. Do NOT touch the main function. If you do, the Checker will give you a Wrong Answer verdict.
2. Write all your code in the mentioned function.
3. You may add print statements inside that function for debugging, but remember to comment them out before running Checker.bat.
4. Don't forget to answer the short questions/MCQs.


Before ending the quiz:
1. Make sure you have written your student ID in the question script. Otherwise, you will not get any marks for the short questions.
2. Save the Solution.java or Solution.py file.
3. Remove any print statements you have written yourself before quiz time ends.
